# CareerWise Restructured Directory Plan

## 1. User Types & Their Specific Needs

Based on your onboarding flow, I can identify these 4 user types:

### High School Students
- **Focus**: Career exploration, college planning, skill discovery
- **Features**: Assessment center, learning paths, goal setting, career exploration

### Recent Graduates  
- **Focus**: Job search, resume building, interview prep, entry-level opportunities
- **Features**: Resume builder, interview practice, job matching, networking

### Working Professionals
- **Focus**: Career advancement, skill development, performance improvement
- **Features**: Skills assessment, learning paths, career progression, analytics


## 3. Key Changes & Benefits

### Separation of Concerns
- **Clear user-type boundaries**: Each user type has its own folder with tailored features
- **Shared components**: Common functionality remains in `shared/` folder
- **Persona-aware routing**: Different navigation and features per user type

### Enhanced User Experience
- **Tailored dashboards**: Each user type gets a custom dashboard with relevant widgets
- **Relevant features only**: Students don't see enterprise features, entrepreneurs don't see college planning
- **Personalized branding**: Each user type can have its own color scheme and imagery

### Maintainable Architecture
- **Modular structure**: Easy to add features for specific user types without affecting others
- **Clear boundaries**: Developers know exactly where to add new features
- **Reusable components**: Shared components prevent code duplication
