# 21: Online Courses — goal-driven, India-scoped

**What to build:** A new feature surfacing course recommendations mapped to the student/graduate's stated goal or target field (e.g. "AI Engineer" → relevant ML/programming courses). Static curated reference table for v1, scoped to platforms genuinely accessible in India (Coursera, Udemy, NPTEL/SWAYAM where relevant) — same honesty pattern as the Skill Gap tool: labeled as curated, not exhaustive or live.

**Blocked by:** None

**Status:** ready-for-agent

- [ ] A student/graduate with a stated goal sees course suggestions relevant to that specific goal, not a generic list
- [ ] Reference table covers at least a handful of common goal/field categories (mirroring how Skill Gap's table is structured), not just one hardcoded example
- [ ] UI clearly communicates this is a curated starting point, not a live/exhaustive catalog (same disclaimer pattern as Skill Gap)
- [ ] Course entries link out to the real course pages (Coursera/Udemy/NPTEL etc.), not dead links or placeholders

## Out of Scope

- Any Coursera (or other) affiliate API integration — explicitly deferred to v2 once there's traction to justify pursuing a partnership. Do not build a fake/stub affiliate integration for this ticket.
