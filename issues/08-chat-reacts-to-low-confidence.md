# 08: Chat reacts to low interview confidence

**What to build:** After a mock interview scored low on confidence, reopening the chat has it proactively bring this up with encouragement and a concrete tip — the first end-to-end proof the interlinking model actually works.

**Blocked by:** 06, 07

**Status:** ready-for-agent

- [x] Completing a low-confidence mock interview, then opening chat, produces a chat response that references it unprompted (within the first exchange, not buried)
- [x] The response includes at least one concrete, specific tip (not generic "you'll do great" filler)
- [x] A high-confidence interview does NOT trigger this same proactive framing
